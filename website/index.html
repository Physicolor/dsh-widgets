一条命令安装

从插件市场添加即可——无需改任何配置文件。

dsh-widgets@1.4.0 · DeepSeek Harness 插件 
$ dsh plugin --profile web add dsh-widgets
# 然后硬刷新浏览器（Ctrl+Shift+R），并点击会话顶部的「组件」胶囊展开组件栏。

贡献一个组件

每个组件都必须跨过六道硬门槛；REWORK 是正常迭代，BLOCKED 才是停。

ContractDiscoveryRegistryRuntimeMarketplaceIsolation
  1. 定义需求表 + 完整性检查
  2. 构建规格 → Worker → 组件单元
  3. 验证validate-widget-unit.mjs MVW 硬门槛
  4. 评审独立评审 Agent + 人工评审
  5. 提交注册重生成 → 进入市场
